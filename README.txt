Mis Finanzas - app web (PWA)

Archivos:
  index.html            la app
  manifest.webmanifest  nombre, colores e íconos para instalarla
  sw.js                 hace que funcione sin internet
  icons/                íconos de la app

Para usarla hay que subir TODA esta carpeta a un hosting con https
(por ejemplo Netlify Drop o GitHub Pages). Abrir index.html directo
desde el celular no activa el modo app.
